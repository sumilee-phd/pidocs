11장에서 학습한 동작 분류 모델을 사이버파이에 탑재한다. 기기는 가속도를 0.05초마다 측정해 최근 1초(20개) 측정값을 보관하고, 0.5초(10개)마다 특징을 계산해 동작을 판정한다. 11.1절의 창 크기·이동 간격과 같은 설정이다. 판정 결과는 화면에 동작 이름으로, 본체 LED에 동작별 색으로 표시한다.

!!! warning "예시 자료로 학습한 모델"
    이 절의 `classify` 함수는 11장 예시 자료로 학습한 깊이 3 결정트리를 변환한 것이다. 실측 자료로 다시 학습하면 기준값이 달라지므로, 11.3절의 방법으로 새로 변환한 함수로 교체한다.

## 탑재 프로그램

```python
import time
import cyberpi

W, STEP = 20, 10                  # 창 크기 20개(1초), 이동 간격 10개(0.5초)
COLOR = {"still": (0, 0, 255), "tilt": (0, 255, 0),
         "circle": (255, 255, 0), "shake": (255, 0, 0)}


def mean(v):
    return sum(v) / len(v)


def std(v):
    m = mean(v)
    return (sum((x - m) ** 2 for x in v) / (len(v) - 1)) ** 0.5


def classify(f):
    """11.3절 조건문 모델(예시 자료 학습, 깊이 3)"""
    if f["ax_std"] <= 0.5996:
        if f["ay_std"] <= 0.4518:
            return "tilt" if f["az_mean"] <= 7.4455 else "still"
        return "tilt" if f["az_mean"] <= 9.5005 else "still"
    if f["ay_std"] <= 0.6770:
        return "circle" if f["ax_std"] <= 5.0755 else "shake"
    return "shake"


axs, ays, azs = [], [], []        # 최근 측정값
new = 0                           # 마지막 판정 이후 새로 측정한 개수
cyberpi.console.println("gesture start")
while True:
    axs.append(cyberpi.get_acc("x"))
    ays.append(cyberpi.get_acc("y"))
    azs.append(cyberpi.get_acc("z"))
    if len(axs) > W:              # 최근 W개만 보관
        axs.pop(0); ays.pop(0); azs.pop(0)
    new += 1
    if len(axs) == W and new >= STEP:
        new = 0
        f = {"ax_std": std(axs), "ay_std": std(ays), "az_mean": mean(azs)}
        g = classify(f)
        r, gr, b = COLOR[g]
        cyberpi.led.on(r, gr, b, "all")
        cyberpi.console.clear()
        cyberpi.console.println(g)
    if cyberpi.controller.is_press("b"):   # B 단추로 종료
        cyberpi.led.off("all")
        break
    time.sleep(0.05)
```

| 부분 | 설명 |
|---|---|
| `axs.append(…)`, `axs.pop(0)` | 리스트 끝에 새 측정값을 추가하고 맨 앞의 가장 오래된 값을 제거해 항상 최근 20개만 보관 |
| `new >= STEP` | 새 측정값이 10개 누적될 때마다, 즉 0.5초마다 판정 |
| `f = {…}` | 깊이 3 트리가 사용하는 특징 3개(`ax_std`, `ay_std`, `az_mean`)만 계산 |
| `COLOR` | 정지 파랑, 기울이기 초록, 원 그리기 노랑, 흔들기 빨강 |

11.3절의 `export_text` 출력에서 트리가 사용한 특징은 `ax_std`, `ay_std`, `az_mean` 세 가지뿐이다. 나머지 특징 4개는 판정에 영향을 주지 않으므로 기기에서 계산하지 않는다. 기기의 계산량을 줄이는 방법이다.

## 실습 과제

1. 측정 간격과 판정 간격을 화면에 표시하도록 수정하고(`time.time()` 사용), 실제 판정 간격이 0.5초에 가까운지 확인하시오.
2. 본인의 실측 자료로 학습한 모델을 11.3절 방법으로 변환해 `classify` 함수를 교체하고, 위 표를 다시 작성하시오.
3. 같은 동작이 연속 2회 판정될 때만 화면을 바꾸도록 수정해, 동작을 바꾸는 순간의 잘못된 판정이 화면에 표시되지 않게 하시오(7.4절 연속 판정).

!!! warning "초안 확인 사항"
    이 프로그램은 예시 자료의 측정값을 순서대로 입력하는 가짜 사이버파이 모듈로 시험해, 판정 결과가 11장의 판정과 일치함을 확인했다. Upload 모드에서의 실제 측정 간격, 리스트 연산 속도, 실제 동작에서의 판정 결과는 실기기로 확인한 뒤 확정한다.
