# 12.4 프로젝트 주제 선정

13~16주차에는 팀별로 측정·판정·표시·보고 기능을 갖춘 시스템을 구성하고, 16주차 등교일에 시연한다. 이 과목의 수강생은 현장에서 일하는 학습근로자다. 프로젝트 주제는 각자의 직무 현장에서 관찰한 문제에서 도출한다. 이 절에서는 주제를 정하는 기준과 팀 구성, 자료 사용 원칙을 정리한다.

## 프로젝트 구성 요소

| 구성 요소 | 내용 | 관련 장 |
|---|---|---|
| 측정 | 사이버파이 센서(조도·소리·가속도·Wi-Fi 신호 세기)로 현장 상황을 측정 | 4·8장 |
| 판정 | 분위수 임계값 또는 학습한 모델로 상태를 판정 | 7·10·11장 |
| 표시 | 기기 화면·LED·LED 스트립으로 판정 결과를 표시 | 4·7·12장 |
| 전송·저장 | Wi-Fi로 서버에 전송하고 기록을 저장 | 8·14장 |
| 보고 | 측정 요약을 생성형 AI로 문장화하고 수치를 검증 | 13장 |

## 주제 예시

| 현장 문제 | 측정 | 판정·표시 |
|---|---|---|
| 작업장 소음이 높은 시간대를 알고 싶다 | 소리 크기 | 시간대별 분위수 기준으로 소음 단계 표시, 일일 보고 |
| 창고 구역별 조명이 충분한지 확인하고 싶다 | 조도 | 구역별 기준 미달 판정, 점검 목록 생성 |
| 설비 진동이 평소와 다른 순간을 찾고 싶다 | 가속도 | 이동 z-점수로 이상 진동 검출(7.2절) |
| 사무실 Wi-Fi가 약한 자리를 찾고 싶다 | Wi-Fi 신호 세기 | 지점별 중앙값 지도(8.3절) |
| 작업 자세 중 반복 동작을 세고 싶다 | 가속도 | 동작 분류 모델로 동작 횟수 집계(11장) |

주제를 정할 때 다음 질문에 답할 수 있어야 한다.

1. 누가 어떤 상황에서 판정 결과를 사용하는가?
2. 사이버파이의 센서로 측정할 수 있는가?
3. 판정 기준을 무엇으로 정할 것인가(분위수, 학습 모델, 공개 기준)?
4. 오경보와 미검출 중 어느 쪽을 더 줄여야 하는가(7.3절)?
5. 학교나 가정에서 상황을 재현해 측정할 수 있는가?

## 팀 구성과 역할

팀은 2~3명으로 구성한다. 모든 팀원이 코드를 작성하되, 다음 역할을 나누어 책임을 진다.

| 역할 | 책임 |
|---|---|
| 기기 담당 | 측정·표시 프로그램, 기기 탑재와 시연 준비 |
| 분석 담당 | 판정 기준·모델 학습, 정확도 근거 정리 |
| 서버·보고 담당 | 수신 서버, 생성형 AI 보고와 수치 검증 |

## 회사 자료 사용 금지 원칙

| 원칙 | 내용 |
|---|---|
| 회사 내부 자료 반출 금지 | 회사의 설비 기록, 생산 자료, 사진, 문서를 프로젝트에 사용하지 않는다 |
| 회사 설비 부착 금지 | 사이버파이를 회사 설비에 부착하거나 회사 망에 연결하지 않는다. 회사의 승인이 필요한 사항이다 |
| 재현 측정 | 현장 문제는 학교 실습실이나 가정에서 비슷한 상황을 재현해 측정한다 |
| 개인정보 제외 | 사람의 얼굴, 이름, 위치 기록을 수집하지 않는다 |

현장 문제를 주제로 삼되 자료는 직접 재현해 측정하는 이유는 두 가지다. 회사 자료는 회사의 자산이므로 외부 반출에 승인이 필요하고, 직접 측정한 자료여야 측정 조건과 한계를 정확히 설명할 수 있다.

## 제출 양식

12주차 수업이 끝나기 전에 팀별로 다음 양식을 작성해 제출한다.

| 항목 | 작성 내용 |
|---|---|
| 팀명·팀원 | |
| 현장 문제 | 누가, 어디서, 어떤 문제를 겪는가(3문장 이내) |
| 측정 항목 | 센서, 측정 간격, 측정 장소(재현 방법) |
| 판정 방법 | 임계값 근거 또는 학습 모델 |
| 표시·보고 | 기기 표시 방식, 보고 문장의 사용자 |
| 오류 우선순위 | 오경보와 미검출 중 우선 감소 대상과 이유 |
| 역할 분담 | 기기·분석·서버·보고 |
