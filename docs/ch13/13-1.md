# 13.1 Gemini API 호출

API(Application Programming Interface)는 프로그램이 다른 프로그램의 기능을 사용할 수 있도록 정한 호출 규칙이다. Gemini API를 사용하면 파이썬 코드에서 Google의 생성형 AI 모델에 문장을 보내고 생성된 응답을 받을 수 있다. 8장에서 사이버파이가 수업 서버에 측정값을 보내고 응답을 받은 것과 같은 요청·응답 구조다.

## API 키 발급과 보관

API 키는 API를 호출하는 사용자를 식별하는 문자열이다. 키가 있으면 누구나 그 사용자의 이름으로 API를 호출할 수 있으므로 비밀번호처럼 관리한다.

1. [Google AI Studio의 API 키 페이지](https://aistudio.google.com/apikey)에 Google 계정으로 접속한다.
2. API 키 만들기를 선택하고, 생성된 키를 복사한다.
3. Colab 왼쪽 메뉴의 열쇠 모양 아이콘(보안 비밀)을 선택하고, 이름을 `GEMINI_API_KEY`로 정해 키를 값에 붙여 넣는다. 「노트북 액세스」를 켠다.

| Colab 보안 비밀이나 환경변수에 보관한다 | 코드에는 키의 이름만 남는다 |
| 노출되었다고 판단되면 즉시 삭제하고 새로 발급한다 | AI Studio에서 키를 삭제하면 그 키로 하는 호출이 모두 거부된다 |

## google-genai 라이브러리

Gemini API는 `google-genai` 라이브러리로 호출한다. Colab에서는 다음 명령으로 설치한다(이미 설치되어 있으면 건너뛴다).

```text
!pip install -q google-genai
```

다음 코드는 Colab 보안 비밀에서 키를 읽는다. 키가 없거나 Colab이 아닌 환경에서는 `key`가 `None`이 되며, 이후 코드는 호출을 건너뛰고 끝까지 실행된다.

```python
import os

try:
    from google.colab import userdata
    key = userdata.get("GEMINI_API_KEY")
except Exception:
    key = os.environ.get("GEMINI_API_KEY")     # PC에서는 환경변수 사용

MODEL = "gemini-2.5-flash"                      # 사용 가능한 모델 이름은 공식 문서에서 확인
print("API 키 준비:", key is not None)
```

## 요청과 응답 구조

```python
if key:
    from google import genai
    client = genai.Client(api_key=key)
    response = client.models.generate_content(
        model=MODEL,
        contents="Wi-Fi 신호 세기 단위 dBm의 의미를 고등학생에게 두 문장으로 설명하시오.")
    print(response.text)
    print(response.usage_metadata)
else:
    print("API 키가 없어 호출을 건너뜁니다.")
```

!!! note "실행 결과"
    수업용 API 키를 확인한 뒤 실제 응답과 Colab 실행 화면을 기입한다.

<!-- DATA: ch13_run_basic — 유효한 API 키로 위 코드를 실행한 응답 텍스트·usage_metadata와 Colab 캡처 -->

| 구성 요소 | 의미 |
|---|---|
| `genai.Client(api_key=key)` | API 키로 인증한 클라이언트 생성 |
| `model` | 호출할 모델 이름 |
| `contents` | 모델에 보내는 입력(프롬프트) |
| `response.text` | 생성된 응답 문장 |
| `response.usage_metadata` | 입력·출력 토큰 수. 토큰은 모델이 문장을 처리하는 단위이며 사용량 계산의 기준 |

같은 프롬프트를 여러 번 보내면 응답 문장이 매번 조금씩 다르다. 생성형 AI는 다음에 올 토큰을 확률에 따라 선택하기 때문이다. 이 성질 때문에 13.4절에서 응답을 코드로 검증하는 절차가 필요하다.
