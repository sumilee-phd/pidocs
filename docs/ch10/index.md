# 10장 분류: 다음 날 강수 여부

<span class="chip">10주차</span> <span class="chip on">온라인</span> <span class="chip">기기 불필요</span>

9장에서는 다음 날 평균기온이라는 수치를 예측했다. 이 장에서는 같은 날씨 자료로 다음 날 비가 오는지 여부를 예측하는 분류 모델을 학습한다. 결정트리 분류기를 사용하고, 정확도만으로는 판정할 수 없는 분류 모델의 성능을 혼동행렬·재현율·정밀도로 분석한다. 이 장에서 확인하는 결정트리의 조건문 구조는 11장의 기기 탑재와 12장의 날씨 신호등에 그대로 사용한다.

## 학습 목표

- 연속값 자료에서 분류 레이블을 정의한다.
- 결정트리 분류기를 학습하고 분기 규칙을 해석한다.
- 정확도·혼동행렬·재현율·정밀도로 분류 성능을 판정한다.
- 클래스 불균형과 과대적합이 성능에 미치는 영향을 설명한다.
