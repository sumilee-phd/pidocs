# AI 파이썬 피지컬컴퓨팅

<span class="chip">2027 P-TECH</span> <span class="chip">16주</span> <span class="chip on">온라인 12주</span> <span class="chip off">오프라인 4주</span>

이 책은 사이버파이(CyberPi)를 교구로 사용하는 AI 파이썬 실습서다. 센서로 측정한 자료와 공개 기상 자료를 파이썬으로 분석하고, 머신러닝 모델을 학습한 뒤, 그 판정 결과를 LED 스트립과 화면으로 다시 출력하는 과정을 16주에 걸쳐 실습한다.

## 이 책의 구성

| 부 | 장 | 주차 | 주요 실습 |
|---|---|---|---|
| 1부 센서 데이터와 파이썬 기초 | 1~4장 | 1~4주 | 블록 코딩, Colab, 서울 날씨 자료 첫 분석, 사이버파이 측정, LED 스트립 점등 |
| 2부 데이터 분석과 규칙 기반 판정 | 5~8장 | 5~8주 | pandas 정리, 시각화, 소음 단계 LED 신호등, 무선 전송 |
| 3부 머신러닝과 기기 탑재 | 9~12장 | 9~12주 | 다음 날 기온 회귀, 강수 여부 분류, 동작 분류, 날씨 신호등 |
| 4부 생성형 AI 연동과 프로젝트 | 13~16장 | 13~16주 | Gemini API 보고서, FastAPI 서버, 팀 프로젝트 시연 |

## 수업 진행 방식

이 과목은 온라인 3주와 오프라인 1주를 반복한다. 오프라인 주(4·8·12·16주차)에는 사이버파이로 자료를 수집하거나 모델을 기기에 탑재한다. 온라인 주에는 오프라인 주에 수집한 자료와 공개 자료를 Colab에서 분석하고 모델을 학습한다. 기기를 대여받은 경우에는 온라인 주에도 USB로 연결한 Live 모드 실습을 병행한다.

| 구분 | 장소 | 사용 도구 | 기기 |
|---|---|---|---|
| 온라인 주 | 각자의 PC | Colab, 웹 브라우저 | 대여 시 USB 연결 |
| 오프라인 주 | 교내 실습실 | mBlock, 수업 서버, 교내 Wi-Fi | 1인 1대 |

## 준비물

- 구글 계정(Colab·Gemini API 사용)
- 개인 PC(회사 지급 PC는 보안 정책상 프로그램 설치가 제한될 수 있다)
- 사이버파이와 포켓쉴드, LED 스트립(오프라인 주에 배부)
- 실습 자료: [서울 일별 날씨 자료 2021~2025(CSV)](data/seoul_weather_2021_2025.csv)

## 표기 규칙

- 코드는 회색 상자에 표기한다. 상자 오른쪽 위의 복사 단추로 코드를 복사해 Colab이나 mBlock에 붙여 넣는다.
- 실행 결과는 코드 바로 아래에 「실행 결과」로 표기한다. 본문의 수치는 저자가 같은 코드를 실행해 얻은 값이다.
- 기기 실습 절에는 실행 모드(Live 또는 Upload)를 절 첫머리에 표기한다.
- 처음 등장하는 전문용어는 원어를 괄호 안에 함께 적는다.
