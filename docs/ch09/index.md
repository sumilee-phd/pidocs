# 9장 머신러닝 시작: 날씨 회귀

<span class="chip">9주차</span> <span class="chip on">온라인</span> <span class="chip">기기 불필요</span>

7장까지는 사람이 분포를 확인하고 임계값을 직접 정했다. 이 장에서는 자료에서 입력과 출력의 관계를 자동으로 학습하는 머신러닝(machine learning)을 시작한다. 2021~2025년 서울 일별 날씨 자료로 다음 날 평균기온을 예측하는 회귀 모델을 학습하고, 단순한 기준선 모델과 비교해 모델의 유효성을 판단한다.

## 절 구성

- [9.2 날씨 자료의 특징과 레이블](9-2.md)

## 학습 목표

- 지도학습의 구성 요소(특징·레이블·모델·평가)를 구분한다.
- 시계열 자료를 시간 순서로 분할하는 이유를 설명한다.
- 선형회귀 모델을 학습하고 MAE·RMSE·결정계수를 해석한다.
- 기준선 모델과의 비교로 모델의 유효성을 판정한다.
