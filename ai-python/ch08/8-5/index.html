    8.5 제스처 데이터 수집¶

    11장에서는 사이버파이를 들고 하는 동작을 가속도 측정값으로 분류하는 모델을 학습한다. 이 절에서는 그 학습 자료를 수집한다. 모델의 성능은 자료의 품질에 좌우되므로, 모든 학생이 같은 동작 정의와 같은 기록 규칙을 따른다.

    동작 4종 정의¶

    동작 이름(파일 표기) 동작 시간
    정지(still) 기기를 화면이 위를 향하도록 손바닥에 올리고 움직이지 않는다 2초
    흔들기(shake) 기기를 쥐고 좌우로 빠르게 흔든다(약 4~5회 왕복) 2초
    기울이기(tilt) 화면이 위를 향한 상태에서 앞쪽으로 천천히 약 45° 기울였다가 되돌린다 2초
    원 그리기(circle) 기기를 쥐고 공중에 지름 약 20 cm의 원을 한 번 그린다 2초

    기록 규칙¶

    항목 규칙
    반복 횟수 동작마다 1인 30회
    1회 기록 A 단추를 누르면 2초 동안 0.05초 간격으로 가속도 3축 기록(약 40행)
    실행 모드 Live 모드(PC에 CSV로 저장)
    파일 단위 동작 1종 × 1인 = 파일 1개(30회 포함)
    파일 이름 g_동작_번호.csv(예: g_shake_07.csv)
    열 구성 rep(회차 1~30), t(회차 시작 후 경과 초), ax, ay, az

    파일 이름의 번호는 수강생 번호 두 자리다. 학생 이름은 파일 이름과 내용에 넣지 않는다.

    수집 프로그램¶

    import cyberpi
import time
import csv
import os

GESTURE = "shake"          # still / shake / tilt / circle 중 하나
STUDENT = "07"             # 수강생 번호 두 자리
REPS = 30
DURATION = 2.0             # 1회 기록 시간(초)
INTERVAL = 0.05            # 측정 간격(초)

name = "g_%s_%s.csv" % (GESTURE, STUDENT)
path = os.path.join(os.path.expanduser("~"), "Desktop", name)

with open(path, "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["rep", "t", "ax", "ay", "az"])
    for rep in range(1, REPS + 1):
        cyberpi.console.clear()
        cyberpi.console.println("%s %d/%d" % (GESTURE, rep, REPS))
        cyberpi.console.println("press A")
        while not cyberpi.controller.is_press("a"):   # A 단추를 누를 때까지 대기
            time.sleep(0.02)
        cyberpi.led.on(255, 0, 0, "all")              # 기록 중 빨간색
        t0 = time.time()
        while time.time() - t0 < DURATION:
            w.writerow([rep, round(time.time() - t0, 3),
                        cyberpi.get_acc("x"), cyberpi.get_acc("y"), cyberpi.get_acc("z")])
            time.sleep(INTERVAL)
        cyberpi.led.off("all")
        time.sleep(0.5)

cyberpi.console.println("saved")
print("저장 완료:", path)

    LED가 빨간색으로 켜져 있는 2초 동안 동작을 수행한다. LED가 꺼진 뒤 다음 회차를 위해 처음 자세로 돌아가 A 단추를 누른다. 동작을 잘못 수행한 회차가 있으면 회차 번호를 메모해 두고, 11장 분석 전에 해당 회차를 제외한다.

    수집 후 확인¶

    import pandas as pd

g = pd.read_csv("g_shake_07.csv")
print(g["rep"].nunique(), "회")
print(g.groupby("rep").size().describe().round(1))
g.groupby("rep")[["ax", "ay", "az"]].std().mean().round(2)

    회차 수가 30이고 회차당 행 수가 비슷하면 정상이다. 마지막 줄은 회차별 표준편차의 평균이다. still 파일은 표준편차가 작고 shake 파일은 크게 산출되어야 한다. 11.1절에서 이 차이를 분류 특징으로 사용한다.

    초안 확인 사항

    가속도 함수 이름은 mBlock 블록 변환(4.6절)으로 확인했다. Live 모드에서 0.05초 간격 측정이 실제로 가능한지(USB 통신 지연), 회차당 실제 행 수, 동작 정의의 구분 가능성은 11/16 주 실물 작업에서 확인한 뒤 확정한다.
