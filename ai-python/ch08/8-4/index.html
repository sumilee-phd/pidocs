    8.4 실기 과제: 수집·판정·표시 프로그램¶

    4~8장에서 학습한 측정(4.6절), 판정(2.4·7.1절), 표시(4.5·7.4절), 전송(8.2절)을 하나의 프로그램으로 결합한다. 수업 시간 안에 완성하고, 교수자 앞에서 동작을 시연한다.

    과제 조건¶

    번호 조건
    1 Upload 모드로 동작하며, USB를 분리하고 포켓쉴드 배터리로 실행한다
    2 조도 또는 소리 크기 중 하나를 0.5초 간격으로 측정한다
    3 측정값을 정상·주의·경고 3단계로 판정한다. 임계값은 4주차에 수집한 자료의 분위수를 근거로 정하고, 근거를 주석에 적는다
    4 본체 LED 5개의 색으로 단계를 표시하고(초록·노랑·빨강), 화면에 측정값과 단계 이름을 표시한다
    5 경고 단계는 연속 3회 이상일 때만 표시한다(7.4절 연속 판정)
    6 A 단추를 누르면 측정을 시작하고, B 단추를 누르면 정지한다
    7 10회 측정할 때마다 최근 10회의 중앙값을 수업 서버로 전송하고, 전송 결과를 화면에 표시한다

    조건 7에서 10개의 중앙값은 정렬한 리스트의 5번째와 6번째 값의 평균이다(7.4절의 정렬 방법). MicroPython에서는 pandas를 사용할 수 없으므로 리스트와 sorted()로 산출한다.

    시연 점검 기준¶

    점검 항목 확인 방법
    USB 없이 동작 교수자가 USB를 분리한 상태에서 전원을 켜고 시작
    측정 간격 화면에 표시되는 측정값이 약 0.5초마다 바뀌는지 확인
    임계값 근거 코드 주석의 분위수 근거와 4주차 자료를 대조
    3단계 표시 센서를 가리거나 소리를 내어 초록·노랑·빨강이 모두 표시되는지 확인
    연속 판정 손뼉 한 번에는 경고가 표시되지 않고, 계속 소리를 내면 경고가 표시되는지 확인
    단추 동작 A로 시작, B로 정지되는지 확인
    서버 전송 수업 서버 화면에 10회마다 기록이 추가되고 기기 화면에 전송 결과가 표시되는지 확인

    시연 중 동작하지 않는 항목이 있으면, 원인을 화면 출력과 코드로 설명한다. 원인을 정확히 설명하는 것도 점검 항목에 포함한다.
